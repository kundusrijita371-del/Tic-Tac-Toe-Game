# Tic-Tac-Toe Game<br>

A classic, interactive Tic-Tac-Toe web game built for two players to enjoy a quick match with a clean user interface.<br>

<h2>📎 Features</h2>
* **Interactive Gameplay**: Smooth turn-based mechanics for Player X and Player O.<br>
* **Smart State Detection**: Automatically checks for winning combinations, ties, and resets the board instantly.<br>
* **Responsive Design**: Fully optimized layout that works seamlessly across desktop and mobile screens.<br>

<h2>▶ Getting Started</h2>
To run this project locally, follow these simple steps:<br>
* Clone the repository to your local machine using git.<br>
* Open the project folder in your preferred code editor.<br>
* Launch the application by opening the main file in your web browser.<br>

<h2>⚒️ How to Play</h2>
* Player X always takes the first turn by clicking on any empty grid cell.<br>
* Players alternate turns placing their respective marks until one player aligns three in a row.<br>
* If all cells fill up without a winning line, the game declares a draw.<br>
