# Tic-Tac-Toe Game

A classic, interactive Tic-Tac-Toe web game built for two players to enjoy a quick match with a clean user interface.

<h2>📎 Features</h2>
* **Interactive Gameplay**: Smooth turn-based mechanics for Player X and Player O.
* **Smart State Detection**: Automatically checks for winning combinations, ties, and resets the board instantly.
* **Responsive Design**: Fully optimized layout that works seamlessly across desktop and mobile screens.

<h2>▶ Getting Started</h2>
To run this project locally, follow these simple steps:
* Clone the repository to your local machine using git.
* Open the project folder in your preferred code editor.
* Launch the application by opening the main file in your web browser.

<h2>⚒️ How to Play</h2>
* Player X always takes the first turn by clicking on any empty grid cell.
* Players alternate turns placing their respective marks until one player aligns three in a row.
* If all cells fill up without a winning line, the game declares a draw.
